Учебный проект · 3 курс · весна 2026 · длительность — 1 семестр

«Лапа помощи» — концепция платформы для координации волонтёрской помощи животным. Сервис должен подбирать задачи с учётом навыков, местоположения и доступности волонтёра, снижая информационный хаос и помогая эффективнее распределять помощь.

Что я делала:
- исследовала рынок цифровых сервисов помощи животным в России;
- классифицировала существующие решения и изучила ключевых игроков;
- провела конкурентный анализ российских и зарубежных платформ;
- разобрала пользовательские сценарии и механики взаимодействия конкурентов;
- сформулировала выводы и рекомендации для продукта;
- исследовала механики вовлечения и удержания разных групп пользователей.

Ключевое решение:
Основой продукта стала персонализированная выдача задач: вместо общего потока запросов волонтёр получает релевантные предложения по навыкам, интересам и местоположению. В исследовании также выделила механики, которые помогают сделать вклад пользователя видимым и уменьшить перегрузку.

Результат:
На основе исследования рынка и поведения существующих сервисов сформировала рекомендации для структуры продукта, пользовательских сценариев и механик вовлечения платформы.
